Git -> trace the history
    -> help to collaborate 

Github -> website to store and manage code
       -> commit - changes

local -> laptop/pc
remote -> Github

git config --global user.name "Name"
git config --global user.email "Email"

git config --list -> to check name and email

git clone <link> -> to clone a repo

cd -> change directory 

ls -> all list files
ls -a -> list all files even hiddens

git status -> gives the status of the folder
           -> untracked - new files that git doesn't yet track
           -> modified - changed
           -> staged - file is ready to be committed
           -> unmodified - unchanged

git add <file name> -> to add file to git 
git add . -> to add all files to git 

git commit -m "message" -> record of change

git push origin main -> upload local repo to remote repo
                     -> origin - default remote repo

git init -> to create a new git repo
git remote add origin <link> -> to make origin connected to the default remote repo
git remote -v -> to verify the remote repo
git branch -> to check branch

branches -> copies of the repo

git branch -M main -> to rename a branch
git push -u origin main -> to set origin main as upstream to avoid writing origin main 


git branch -> to check branch
git branch -M main -> to rename a branch
git checkout <branch_name> -> to navigate 
git checkout -b <new-branch-name> -> to create new branch
git branch -d <branch-name> -> to delete branch

git pull origin main -> to make remote repo merge changes into local repo

merge conflict -> when git doesn't able to make changes

git reset -> to undo all the changes(this is when added)
git reset HEAD~1 -> to undo committed changes (for one commit only)

git reset <commit-hash> -> to undo all changes till this commit
git reset --hard<commit-hash> -> to all remove code form local repo

git log -> history of all commits
